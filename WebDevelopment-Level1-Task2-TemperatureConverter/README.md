# Temperature Converter

## About
An interactive web application that converts temperatures between Celsius, Fahrenheit, and Kelvin.

## Technologies
- HTML5
- CSS3
- JavaScript

## Features
- Celsius to Fahrenheit conversion
- Fahrenheit to Celsius conversion
- Celsius and Fahrenheit to Kelvin
- Input validation
- Absolute zero validation
- Responsive UI

## How to Run
Open `index.html` in a web browser.
